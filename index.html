How to use on your phone

  1. Open this website in Chrome or Safari.
  2. Tap Choose video and select a file.
  3. Set the start and end times, then tap Create my clip.
  4. Download the finished MP4 to your phone.

Tip: For very long recordings, first make a shorter source file. Mobile browsers can run out of memory on multi-hour videos.
